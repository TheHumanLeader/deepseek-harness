# @deepseek-ai/dsh-agent-guidance

[English](README.md) | 中文

主 Agent、项目指令和受管理辅助 Agent 的实时配置。它只处理两个问题：Agent 超出用户要求的阶段直接行动，以及资料已经足够后仍继续检索。

每次顶层模型请求前，本插件都会组合最新的全局提示词、匹配目录最深的项目提示词和当前辅助 Agent 列表。项目可以只排除用户配置的全局提示词。组合结果发生变化时，系统追加一条持久快照，并注明它替代之前的 Agent 配置。辅助 Agent 不接收主 Agent 的这份快照。

四个内置辅助 Agent ID 是 `researcher`、`project-explorer`、`reviewer` 和 `agent-manager`。用户可以修改它们，但不能删除：设置中缺失的内置 Agent 会由系统恢复。用户创建的 Agent ID 使用小写字母、数字和连字符。`managed_agent` 启动辅助 Agent 时，实时读取其提示词、可选模型和工具白名单。

`researcher` 默认只能使用 `web_search`。它先读用户提供的资料，优先使用官方或一手来源，每次搜索只解决一个未回答的问题；答案已经足够或下一次搜索没有新增信息时停止。

## 模型体验

### 实时 Agent 配置快照

#### 模型看到的内容

主 Agent 会看到一段 `<system-reminder>`，其中包含最新的全局指令、匹配的项目指令，以及可以使用的辅助 Agent ID 和用途。配置改变后，新快照会注明它替代之前的 Agent 配置快照。

#### Token 影响

提示词会增加已启用的全局指令、匹配的项目指令，以及每个辅助 Agent 的一行说明。配置未改变时不会新增消息；配置改变时会追加一条可重放快照。

#### KV 缓存影响

配置未改变时，请求前缀保持不变。配置改变时，下一次模型请求前会追加新消息，因此请求前缀会增长。

## 已知限制和后续工作

- 提示词用于改善指令遵循，不会扩大 Agent 权限或绕过审批。
- 主 Agent 的模型仍由现有模型设置管理，完整工具组合仍由 Agent 预设管理。
