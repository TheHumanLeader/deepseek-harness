# @deepseek-ai/dsh-client-ui-agent-guidance

[English](README.md) | 中文

`agent-guidance` 设置命名空间的 Web 页面。一个页面管理全局主 Agent 提示词、项目提示词、项目排除全局提示词的开关、四个不可删除的内置辅助 Agent，以及用户创建的辅助 Agent。

每个辅助 Agent 可以设置 ID、名称、用途、提示词、可选的模型服务和模型、准确的工具白名单，以及是否允许继续委派。内置辅助 Agent 可以修改，但不能删除，也不能继续委派。保存后，从下一次模型请求开始作用于当前会话和新会话。

浏览器包本身不会向模型发送内容。提示词组合、持久快照、项目匹配、内置 Agent 恢复和启动时的实时配置读取由 `@deepseek-ai/dsh-agent-guidance` 负责。

## 模型体验

本页面通过 `@deepseek-ai/dsh-agent-guidance` 的实时配置间接影响模型，不直接发送模型内容。

#### KV 缓存影响

保存变更后，下一次模型请求前会追加新的 Agent 配置快照。内容不变时不会追加。

## 已知限制和后续工作

- 主 Agent 的模型和完整工具组合仍在现有的“模型”和“Agent 预设”页面管理。
- 辅助 Agent 的工具名目前使用文本输入，因为主机尚未向本页面提供工具名目录。
